## QuickMart Store System

A console-based retail and order management application built entirely in Java. This project simulates the daily operations of a retail store, handling inventory, customer registration, and billing without the need for an external database.

---

### Key Features
*   **Product Management:** Add, view, and search products across multiple categories.
*   **Customer Registration:** Store and manage customer details seamlessly in memory.
*   **Order Processing:** Create orders, add multiple items, and automatically check inventory availability before confirming.
*   **Automated Billing:** Automatically calculates subtotals, applies a standard 5% discount, and adds 18% tax to the final checkout amount.
*   **Payment Simulation:** Supports simulated transactions via UPI, Credit Card, and Cash utilizing Java interfaces.
*   **Sales Reports:** Generates real-time summaries of total orders and overall store revenue.

---

### Technologies Used
*   **Language:** Java
*   **Architecture:** Object-Oriented Programming (OOP) 
*   **Storage:** In-Memory Java Collections (Lists)
*   **Design:** Interface-driven polymorphic payment processing and Enum-based state management.

---

### How to Run
1. Clone this repository to your local machine.
2. Ensure you have the Java Development Kit (JDK) installed.
3. Compile and run the `Main.java` file located in the `src` folder.
4. Follow the interactive console menu (options 1-7) to navigate the system.
